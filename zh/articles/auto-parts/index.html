中国汽配卡车发伊朗

中国汽配走公路发伊朗。从新疆出，两条走廊，到德黑兰场站大约 22 天。不是到门。不是海运。

乌恰卡航

新疆 → 吉尔吉斯斯坦 → 乌兹别克斯坦 → 土库曼斯坦 → 伊朗。

运费单询。过吉尔吉斯，再加货值发票税 0.4%。运费和这 0.4% 是两笔。

霍尔果斯

新疆 → 哈萨克斯坦 → 乌兹别克斯坦 → 土库曼斯坦 → 伊朗。

运费单询。不加这 0.4%。

两条到德黑兰场站都大约 22 天。目的城：马什哈德、德黑兰、萨拉赫斯。交货在场站。马什哈德、萨拉赫斯天数另说，询盘写目的城，别默认都是 22 天。

货类：汽配、电子、机械、建材。这一页说汽配。品名写清：轴承、刹车片、滤芯，别写「配件一批」。危化、两用、要证，第一条就写。

0.4% 只在乌恰。霍尔果斯不加。哪条更便宜，网页不比。乌恰还是霍尔果斯：0.4%只在一条路上

网上不挂运价。要报价，发四样：

  1. 货名（品名）
  2. 件数、重量
  3. 目的城：马什哈德 / 德黑兰 / 萨拉赫斯
  4. 口岸：乌恰 或 霍尔果斯

缺一项，不报价。新疆卡车发伊朗怎么询
