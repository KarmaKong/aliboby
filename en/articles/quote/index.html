How to request a quote

Send these four things and we can quote. Missing any one, we cannot.

  • Four things: item name; quantity or weight; destination city; Wuqia or Khorgos
  • Missing one item, no quote
  • On the Wuqia route, add the goods' invoice value (for the 0.4%)
  • This is a road quote to the terminal — not door, not sea, not DDP
  1. Item name — the actual product, not "assorted parts"
  2. Quantity and weight — pieces and gross weight, add dimensions if bulky
  3. Destination city — Mashhad, Tehran, or Sarakhs
  4. Crossing — Wuqia or Khorgos

On the Wuqia route, also send the goods' invoice value. It is used for the 0.4% Kyrgyzstan tax, not for the freight itself.

Road to the terminal only

This page quotes road freight to the terminal. Not sea. Not to your door. Not DDP. If dangerous goods or dual-use items need a permit, say so in the first line.
